# Prompt para Gemini — Material Visual Instagram Hi Cleo

Use este prompt no Gemini para gerar ideias de postagens e pedir imagens.

---

## Prompt de contexto (cole primeiro)

```
Você é o social media da Hi Cleo, uma secretária virtual de WhatsApp para profissionais autônomos e pequenas empresas brasileiras (corretores, personal trainers, clínicas, professores, prestadores de serviço).

SOBRE O PRODUTO:
- Nome: Hi Cleo (hicleo.com.br)
- A Cleo organiza contatos, faz acompanhamento automático de clientes e envia lembretes. Tudo pelo WhatsApp, sem painel web.
- Público: pequenos empresários que usam WhatsApp como ferramenta principal de vendas e atendimento
- Tom: amigável, direto, sem jargão técnico. Fala a língua do pequeno empresário.
- Paleta: verde WhatsApp (#25D366, #128C7E, #075E54), fundo claro, visual moderno e limpo
- Persona: Cleo é uma secretária virtual simpática, eficiente e moderna. Estilo influencer digital.

REGRAS DE LINGUAGEM:
- Nunca usar: leads, follow-up, CRM, churn, pipeline, onboarding
- Usar no lugar: clientes, acompanhamento, organização de clientes, cancelamento, fila de clientes, primeiros passos
- Falar como se estivesse conversando com o dono de um salão de beleza ou um corretor de imóveis

PLANOS:
- Solo: R$49/mês (1 usuário)
- Equipe: R$119/mês (até 3 usuários)
- Empresa: R$249/mês (até 8 usuários)
- Anual economiza 2 meses
```

---

## Prompt para gerar postagens (cole depois)

```
Crie 10 ideias de postagens para o Instagram da Hi Cleo. Para cada uma, me dê:

1. Tipo (carrossel, reels, post único, stories)
2. Título/gancho (frase que chama atenção)
3. Texto da legenda (curto, com emojis, com CTA)
4. Descrição visual (o que a imagem/vídeo deve mostrar)
5. Hashtags (5-8 relevantes)

Misture entre:
- Posts de dor (problemas que o público tem)
- Posts de solução (como a Cleo resolve)
- Posts educativos (dicas de atendimento)
- Posts de prova social (resultados, depoimentos)
- Posts de bastidores (como funciona por dentro)

O feed deve ter identidade visual consistente: fundo verde ou branco, tipografia moderna, mockups de WhatsApp quando fizer sentido.
```

## Prompt para gerar imagens (use no Gemini com geração de imagem)

```
Crie uma imagem para post de Instagram no formato quadrado (1080x1080px).

Estilo: moderno, limpo, profissional mas acessível.
Paleta: verde (#25D366) como cor principal, fundo branco ou verde escuro (#075E54), texto branco ou escuro para contraste.
Tipografia: sans-serif bold para títulos, regular para subtítulos.

[DESCREVA O POST ESPECÍFICO AQUI]

Exemplos de pedidos:
- "Post com mockup de celular mostrando conversa no WhatsApp com a Cleo respondendo um cliente"
- "Carrossel slide 1: título 'Quantos clientes você perdeu essa semana?' em fundo verde escuro com emoji pensativo"
- "Post comparativo: lado esquerdo 'Sem a Cleo' (bagunça, post-its), lado direito 'Com a Cleo' (organizado, WhatsApp)"
```

```

Requisitos:
- Formato: circular, 1080x1080px
- Personagem: mulher jovem estilizada (estilo 3D cartoon, como avatares da Apple Memoji)
- Expressão: sorriso simpático e confiante
- Cabelo: castanho escuro, moderno
- Roupa: blusa verde (#25D366) profissional mas casual
- Fundo: gradiente verde suave (#25D366 para #128C7E)
```

## Prompts para Artes de Postagens

### Post 1 — Dor (formato quadrado)
```
Crie uma imagem para Instagram, formato quadrado 1080x1080px.

Fundo: verde escuro (#075E54)
Texto principal (branco, bold, centralizado): "Quantos clientes você perdeu por esquecer de responder?"
Texto secundário (branco/70%, menor): "A maioria dos profissionais perde pelo menos 3 por semana"
Elemento visual: emoji 😰 grande no canto superior direito
Rodapé: logo "Hi Cleo" pequeno + @hicleo
Estilo: limpo, moderno, impactante
```

### Post 2 — Solução (formato quadrado)
```
Crie uma imagem para Instagram, formato quadrado 1080x1080px.

Fundo: branco
Lado esquerdo: mockup de celular com conversa WhatsApp (balões verdes e brancos)
Lado direito: texto "A Cleo organiza seus clientes direto no WhatsApp" em verde escuro (#075E54), bold
Abaixo do texto: 3 bullets com ícones verdes:
- ✅ Contatos salvos automaticamente
- ✅ Lembretes de retorno
- ✅ Respostas fora do horário
Rodapé: "A partir de R$49/mês" + logo Hi Cleo
Estilo: clean, profissional, verde como cor de destaque
```

### Post 3 — Comparativo (carrossel slide 1)
```
Crie uma imagem para Instagram, formato quadrado 1080x1080px.

Layout dividido ao meio verticalmente:
- Lado esquerdo (fundo vermelho claro): "Sem a Cleo" — ícones de bagunça (post-its, mensagens perdidas, relógio com X)
- Lado direito (fundo verde claro): "Com a Cleo" — ícones de organização (checklist, WhatsApp, sino de lembrete)
Título no topo: "Antes vs Depois"
Estilo: flat design, ícones simples, contraste claro entre caos e organização
Rodapé: @hicleo
```
