# Briefing — Landing Page WhatsApp-first CRM

## Objetivo da Página

Converter visitantes (pequenos empresários, autônomos, prestadores de serviço) em assinantes pagantes. A página deve comunicar o valor do produto de forma clara, rápida e mobile-first.

## Público-Alvo

- Corretores de imóveis
- Professores particulares
- Clínicas e consultórios pequenos
- Prestadores de serviço (encanador, eletricista, personal trainer)
- Pequenos lojistas
- Consultores e coaches

**Perfil:** Usa WhatsApp como ferramenta principal de vendas/atendimento. Não tem tempo pra aprender sistemas complexos. Quer algo que funcione no celular, sem painel web.

## Tom e Estilo Visual

- **Tom:** Direto, amigável, confiante. Sem corporativês.
- **Estilo:** Moderno, limpo, com identidade verde forte remetendo ao WhatsApp.
- **Mobile-first:** A maioria do público vai acessar pelo celular.
- **Sem jargão técnico:** Falar a língua do pequeno empresário.
- **Personagem digital:** A secretária virtual deve ter uma representação visual como personagem digital / influencer virtual (estilo 3D estilizado ou ilustração moderna). Ela aparece em vários pontos da página como se estivesse "conversando" com o visitante. Transmite simpatia, profissionalismo e modernidade.

### Regras de Linguagem (IMPORTANTE)

O público NÃO conhece termos corporativos. Usar linguagem do dia a dia:

| ❌ NÃO usar | ✅ Usar no lugar |
|-------------|-----------------|
| Leads | Clientes / Contatos |
| Follow-up | Acompanhamento / Retorno / Lembrete |
| CRM | Organização de clientes / Secretária virtual |
| Churn | Cancelamento |
| Conversão | Fechar venda / Conseguir cliente |
| Pipeline | Fila de clientes / Clientes em andamento |
| Onboarding | Configuração inicial / Primeiros passos |
| IA contextual | Respostas inteligentes |

A página deve ser entendida por qualquer pessoa que usa WhatsApp pra trabalhar, sem precisar googlar nenhum termo. Manter profissionalismo e credibilidade sem parecer "sistema de empresa grande".

## Paleta de Cores

- **Verde principal (WhatsApp):** #25D366 e variações (gradientes com #128C7E)
- **Verde escuro (fundo de seções):** #075E54 ou #1a1a2e com overlay verde
- **Fundo:** Branco ou cinza muito claro para contraste
- **Texto:** Escuro (#1a1a1a) para legibilidade
- **Accent/CTA:** Verde vibrante ou branco sobre fundo verde (manter tudo na paleta verde)
- **Vibe geral:** Verde dominante em toda a página — o visitante deve associar imediatamente ao WhatsApp
